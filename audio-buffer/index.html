Audio Buffer London - Live Coding

Live coding is the practice of writing and changing code while it runs, making programming itself a visible, performative act.

In live coding performances, source code is projected and becomes part of the artistic material, alongside sound, visuals, and timing.

It creates a shared, transparent space where algorithms are composed, modified, and interpreted in real time.

whoami

Guillaume Piccarreta (gcode) is a programmer, musician, and digital artist exploring the interaction between sound and image. After studying digital art at Paris Panthéon-Sorbonne University, he lived in Tokyo for four years, where he developed creative applications, audiovisual performances, and interactive installations. live coding 101

Live coding can be understood as real-time software writing: changing a running program, composing through code, and exposing process as performance.

In Live Coding: A User’s Manual (MIT Press, 2022), the practice is described as "thinking in public," where writing and rewriting code becomes visible, improvisatory, and open-ended.

  • Live coding is not about tools. Algorithms are thoughts. Chainsaws are tools. That's why algorithms are sometimes harder to notice than chainsaws.

algorave

Algorave is made from sounds "wholly or predominantly characterised by the emission of a succession of repetitive conditionals."

It breaks barriers between writing algorithms and making dance music live: humans compose in real time with code, and the dancefloor closes the loop.

why

Live coding is also an inclusive community practice. It creates spaces where artists, developers, and students can learn from each other across disciplines.

It supports collaboration with other artists, helps people become familiar with code, and demystifies programming by making process visible.

  • Process over product: the audience witnesses ideas becoming form.
  • Compact rules can produce rich and evolving sonic structures.
  • Errors become creative material instead of backstage problems.
  • Improvisation is framed by explicit algorithmic constraints.

occ

OCC is a live coding environment for audiovisual performance. You write short code blocks and execute them in real time.

  • Visual scene and audio engine are controlled from the same language.
  • Commands are designed to stay compact while performing.
  • Switch from object-level coding to macro sequencing with the 4x4 grid.

Live process

  • Reset and set a base camera.
  • Start one or more audio layers (sound, inst, seq).
  • Add visual groups and triggers.
  • Move across scripts with grid commands.
