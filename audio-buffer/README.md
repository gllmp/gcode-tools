# Audio Buffer — Live Coding Mini Site

Minimal web presentation scaffold for Audio Buffer London session #02.

## Run locally

1. Open `index.html` directly in a browser, or
2. Run a local server:

```bash
cd audio-buffer-mtuk
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Console commands

- `help`
- `next` / `n`
- `prev` / `p`
- `goto <slide-id|number>`
- `list`
- `where`
- `clear`
